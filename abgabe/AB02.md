## Aufgabe 1: Verstöße in NHPlus identifizieren

> **Richtwert:** ca. 10–15 Verstöße über alle drei Bereiche zusammen. Die Anzahl der Tabellenzeilen unten ist **kein Limit** — fügt so viele Zeilen hinzu, wie ihr Verstöße findet, und löscht ungenutzte. Die Tiefe der Begründung in der Spalte „Warum problematisch" zählt mehr als die reine Anzahl.

### a) Sicherheitsmaßnahmen (Art. 32 DSGVO)

| Verstoß                         | DSGVO-Artikel  | Warum problematisch                                                                                                                                  |
|---------------------------------|----------------|------------------------------------------------------------------------------------------------------------------------------------------------------|
| Datenbank Zugang                | §32 1a         | SQLite Datenbanken haben keine möglichkeit, Zugangsberechtigung einzurichten, und sind Unverschlüsselt. Andere Programme Könnten frei von ihr lesen. |
| Fehlende Authentifikation       | §32 1b         | Das Programm hat kein Feature mit welchem sich Authoratisiert werden kann, wodurch alle daten von allen Personen einsehbar sind.                     |
| Fehlende Authorisation          | §32 2          | Das Programm erlaubt jeden Nutzer, die Daten anderer zu verändern.                                                                                   |
| Keine Verschlüsselung der Daten | §32 1a          | Personbezogende Daten, wie der Name und Geburtstag, werden nicht Pseudoanonymisiert oder Verschlüsselt, wodurch.                                     |
|                                 |                |                                                                                                                                                      |
|                                 |                |                                                                                                                                                      |

### b) Grundprinzipien der Datenverarbeitung (Art. 5 DSGVO)

| Verstoß | DSGVO-Artikel | Warum problematisch |
|---|------------|---|
| Vermögensdaten ohne Pflegezweck | §5 1 lit. b | Das Feld "assets" speichert z. B. "arm" oder "vermögend", was keinen Bezug zur Pflege hat.                                                           |
| Überflüssige Vermögenserhebung | §5 1 lit. c | Vermögensdaten sind für die Pflegedokumentation nicht nötig und sollten gar nicht erst erfasst werden.                                               |
| Kein Löschkonzept | §5 1 lit. e | Daten werden unbegrenzt aufbewahrt, es gibt keine automatische Löschung nach Ablauf einer Frist.                                                     |
| Datenbank unverschlüsselt | §5 1 lit. f | Die SQLite Datenbank liegt offen im Dateisystem, jeder mit Zugriff kann alle Gesundheitsdaten lesen.                                                 |
| Keine Einwilligung dokumentiert | §5 1 lit. a | Es gibt keinen Mechanismus, der die Zustimmung des Patienten zur Datenspeicherung einholt oder festhält.                                             |
| Kein Aufnahmedatum gespeichert | §5 1 lit. e | Ohne Zeitstempel lässt sich nicht feststellen, wie lange ein Datensatz schon existiert bzw. eine Löschfrist kann so gar nicht erst berechnet werden. |

### c) Betroffenenrechte (Art. 15–22 DSGVO)

| Verstoß                      | DSGVO-Artikel  | Warum problematisch                                                                                                                |
|------------------------------|----------------|------------------------------------------------------------------------------------------------------------------------------------|
| Kein Recht auf Einschränkung | §18 1          | Es gibt keinen Mechanismus mit dem Gespeichert wird, dass die Daten nur noch gespeichert, aber nicht mehr verwendet werden dürfen. |
| Keine gezielte Berichtigungsfunktion | §16            | Patienten haben das Recht, unrichtige Daten unverzüglich berichtigen zu lassen. Das Projekt bietet keine Möglichkeit für Betroffene, selbst eine Korrektur anzufordern bzw. Änderungen können nur intern durch Pflegepersonal vorgenommen werden, ohne dass ein formeller Berichtigungsprozess existiert.|
|Es gibt keine Auskunftsfunktion für Patienten| §15            | Ein Patient kann nirgendwo nachschauen, welche Daten über ihn gespeichert sind       |
|Es gibt keinen Datenexport für Patienten.| §20             | Ein Patient kann seine Daten nicht als Datei bekommen, um sie woanders weiterzugeben |
